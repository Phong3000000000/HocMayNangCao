# 🔍 DBG-001: RL agents underperform heuristic

**Date**: 2026-05-27
**Status**: ✅ Resolved

## Triệu chứng

Lần training đầu tiên (epsilon_decay=0.9995):
- Q-Learning: Profit ~182 (thấp hơn Random 232!)
- Reorder Threshold: Profit 402

## Giả thuyết

1. ❌ Bug trong environment → Tests passed (50/50)
2. ❌ Reward function sai → Verified: r = rev - purchase - hold - stockout
3. ✅ **Epsilon decay quá nhanh** → Agent không explore đủ trước khi exploit

## Phân tích

```
epsilon_decay = 0.9995 (per step)
steps_per_episode = 30
total_steps_to_min = ln(0.05/1.0) / ln(0.9995) ≈ 5991 steps ≈ 200 episodes

→ Epsilon về 0.05 sau chỉ 200 episodes!
→ Agent chưa thăm dò đủ 2646 states
```

## Giải pháp

Thay đổi hyperparameters:
- `epsilon_decay`: 0.9995 → **0.99998** (reach min at ~5000 episodes)
- `alpha`: 0.1 → **0.15** (learn faster)
- `n_episodes`: 5000 → **8000** (more training)
