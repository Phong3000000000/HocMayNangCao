# 🐛 ERR-001: UnicodeEncodeError cp1252 trên Windows

**Severity**: 🟡 Medium
**Status**: ✅ Fixed
**Date**: 2026-05-27
**File(s)**: `experiments/train.py`, `experiments/evaluate.py`, `experiments/sweep.py`, `visualization/plots.py`, `agents/heuristic_agent.py`

## Mô tả lỗi

Khi chạy `py experiments/train.py` trên Windows, console sử dụng encoding `cp1252` không thể in các ký tự Unicode đặc biệt.

## Stack Trace

```
File "experiments/train.py", line 252, in run_training
    print(f"\n{'═'*60}")
UnicodeEncodeError: 'charmap' codec can't encode characters
in position 2-61: character maps to <undefined>
```

## Nguyên nhân

Windows PowerShell mặc định sử dụng `cp1252` encoding, không hỗ trợ các ký tự:
- Box-drawing: `═`, `─`, `╔`, `╗`, `╚`, `╝`
- Symbols: `✓`, `▸`, `•`, `→`
- Greek: `ε`, `α`, `γ`
- Math: `±`, `×`

## Cách fix

Thay tất cả Unicode chars bằng ASCII equivalents:
- `═` → `=`
- `─` → `-`
- `✓` → `[OK]`
- `▸` → `>`
- `→` → `->`
- `±` → `+-`
- `×` → `x`
- `ε` → `eps`
- `α` → `alpha`
- `γ` → `gamma`

Đặc biệt trong `heuristic_agent.py`:
```python
# Before:
self.name = f"Reorder (inv<{threshold} → order {order_amount})"
# After:
self.name = f"Reorder (inv<{threshold} -> order {order_amount})"
```

## Bài học

> Trên Windows, luôn dùng ASCII cho print statements.
> Chỉ dùng Unicode trong matplotlib (backend Agg render riêng, không qua console).
