Quan ly Ton kho bang Reinforcement Learning

Du an RL Inventory Management — De tai 9, Mon Hoc May Nang Cao.

Agent quyet dinh nhap bao nhieu hang moi ngay de toi da hoa loi nhuan, giam het hang va giam ton kho du.

Yeu cau he thong

  • Python 3.10+ (khong can GPU)
  • pip (di kem Python)
  • Cac thu vien: numpy, matplotlib, pyyaml, streamlit, pytest

Huong dan chay tu dau (cho nguoi tai moi)

Tat ca lenh duoi day chay trong terminal (PowerShell hoac CMD) tai thu muc goc cua du an.

Buoc 1: Clone hoac giai nen du an

# Neu tai tu GitHub:
git clone <link-repo>
cd HocMayNangCao

# Hoac giai nen file zip va mo terminal tai thu muc HocMayNangCao/

Buoc 2: Cai dat dependencies

py -m pip install -r requirements.txt
Neu lenh py khong chay, thu python thay the.

Buoc 3: Kiem thu moi truong (dam bao code hoat dong)

py -m pytest tests/ -v

Ket qua mong doi: 50/50 tests passed. Neu co test FAILED thi dung lai va bao loi.

Buoc 4: Huan luyen cac agents RL

py experiments/train.py
  • Thoi gian: khoang 10-15 phut (20,000 episodes x 10 seeds x 3 agents).
  • Ket qua luu tai results/:
  • q_learning/seed_*.npz — Q-tables cho Q-Learning
  • sarsa/seed_*.npz — Q-tables cho SARSA
  • double_q_learning/seed_*.npz — Q-tables cho Double Q-Learning
  • *_history.json — Lich su training

Buoc 5: Danh gia tat ca agents

py experiments/evaluate.py
  • So sanh 6 agents: Random, AlwaysOrder2, ReorderThreshold, Q-Learning, SARSA, Double Q.
  • Bao cao: mean +- std tren 10 seeds.
  • Kiem tra ca weekend surge (unseen demand pattern).
  • Ket qua luu tai results/evaluation_results.json.

Buoc 6: Tao bieu do

py visualization/plots.py
  • Tao learning curves, agent comparison, policy heatmaps, epsilon schedule.
  • Luu tai reports/figures/.

Buoc 7: Chay Dashboard Demo

py -m streamlit run dashboard/app.py
  • Mo trinh duyet tai dia chi hien thi (thuong la http://localhost:8501).
  • Nhan Ctrl+C trong terminal de dung server.

Dashboard cho phep:

  • Chon agent (Random, Heuristic, Q-Learning, SARSA, Double Q)
  • Chon demand regime (Low/Medium/High)
  • Xem inventory, orders, demand, reward theo ngay
  • Xem bang Policy va Policy Heatmap
  • Xem Learning Curves
  • So sanh tat ca agents

(Tuy chon) Buoc 8: Hyperparameter sweep

py experiments/sweep.py
  • Tim bo hyperparameters tot nhat (alpha, gamma, epsilon_decay).
  • Thoi gian: khoang 30+ phut.

Reward Function

r = revenue - purchase_cost - holding_cost - stockout_penalty
Thanh phanCong thuc
Revenuemin(inventory, demand) x 10
Purchase Costorder x 5
Holding Costremaining_inventory x 0.5
Stockout Penaltymax(0, demand - inventory) x 3

Episode Dynamics (moi ngay)

  1. Dau ngay: inventory += pending_order (cap tai 20)
  2. Agent chon action: dat hang -> pending_order = action
  3. Sinh demand: tu phan phoi roi rac theo demand_regime
  4. Ban hang: sold = min(inventory, demand)
  5. Cuoi ngay: tinh reward, ghi nhan metrics
  6. Episode ket thuc: sau 30 ngay

Thuat toan

Q-Learning (Off-policy)

Q(s, a) <- Q(s, a) + alpha [ r + gamma * max_a' Q(s', a') - Q(s, a) ]

SARSA (On-policy)

Q(s, a) <- Q(s, a) + alpha [ r + gamma * Q(s', a') - Q(s, a) ]

Double Q-Learning

Dung 2 Q-tables de giam overestimation bias:

# Update Q1 (50% probability):
a* = argmax_a Q1(s', a)
Q1(s, a) <- Q1(s, a) + alpha [ r + gamma * Q2(s', a*) - Q1(s, a) ]

# Update Q2 (50% probability):
a* = argmax_a Q2(s', a)
Q2(s, a) <- Q2(s, a) + alpha [ r + gamma * Q1(s', a*) - Q2(s, a) ]
